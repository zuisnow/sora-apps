# sora apps

自分用アプリ置き場。画面（PWA）は GitHub Pages、データは Google Apps Script（GAS）。
GitHub はリポジトリ 1 つ、GAS はアプリごとに別プロジェクト。

```
/                 アプリ一覧（index.html）
/ekiden/          駅伝監督（PWA）
/news/            脳と医工学（PWA）
  config.js       それぞれのアプリがつなぐ GAS の URL を書く場所
/gas/             GAS に貼るコード（GitHub Pages では使わない）
  ekiden/         駅伝用プロジェクト：セーブの保存・読み込み
  news/           ニュース用プロジェクト：収集・配信・しおり同期
```

GAS を分けているので、ニュースのコードを直している途中で壊しても駅伝のセーブには影響しない。
GAS の 1 日の利用上限は Google アカウント単位なので、分けても無料枠は変わらない。

## 1. GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例：`sora-apps`、Public）。
2. この zip の中身をそのままアップロードする（「Add file → Upload files」にフォルダごとドラッグ）。
3. Settings → Pages → Branch を `main` / `/(root)` にして Save。
4. 数分後に `https://<ユーザー名>.github.io/sora-apps/` が開く。駅伝は `…/ekiden/`、ニュースは `…/news/`。

## 2. GAS プロジェクトを作る（アプリごとに 1 回ずつ）

どちらも手順は同じ。https://script.google.com で「新しいプロジェクト」を作り、

| | 駅伝監督 | 脳と医工学 |
|---|---|---|
| プロジェクト名（例） | `ekiden-save` | `news-collector` |
| 貼るコード | `gas/ekiden/Code.gs` | `gas/news/Code.gs` |
| Drive にできるフォルダ | `ekiden-data` | `news-data` |
| setup で起きること | 合言葉の登録 | 合言葉の登録＋1時間ごとの収集トリガー＋初回の収集（1〜2分） |

1. 最初からある `コード.gs` の中身を全部消して、表の「貼るコード」を貼り付ける。
2. 先頭近くの `PASS_PHRASE` を自分だけの合言葉に書き換える（2 つのプロジェクトで別々でもよい）。
3. 関数選択で `setup` を選んで「実行」。権限の確認が出たら許可する
   （「このアプリは確認されていません」→「詳細」→「（安全でないページ）に移動」）。
   ニュースは翻訳と外部サイトへのアクセスの許可も求められる。
4. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
5. 表示された「ウェブアプリ URL」（`…/exec` で終わる）をコピーする。

> コードを直したときは「デプロイを管理」→ 鉛筆 →「バージョン：新バージョン」で更新すると URL が変わらない。

## 3. アプリと GAS をつなぐ

- 駅伝の URL は `ekiden/config.js`、ニュースの URL は `news/config.js` の `gasUrl: ''` に貼って GitHub に上げ直す。
  （アプリの設定画面に直接貼ってもよい）
- 合言葉はアプリの設定画面で入れる（config.js には書かない。リポジトリは公開されるため）。

### 駅伝監督
- 「設定 → クラウド保存」で合言葉を入れて「接続を確認」。
- 「進めるたびに自動で保存する」を ON にしておくと、練習を進めたり大会が終わるたびに（数秒おいて）保存される。
- 別の端末ではタイトル画面の「クラウドから続き」で再開できる。
- バックアップは日ごとに 5 日分、`ekiden-data` フォルダに残る。

### 脳と医工学
- 収集元は `gas/news/Code.gs` 先頭の `NEWS_FEEDS`。Google ニュース検索、Neuroscience News、IEEE Spectrum、ScienceDaily、Medical Xpress、Nature Biomedical Engineering、Journal of Neural Engineering、PubMed、arXiv。検索語を足したり消したりして範囲を変えられる。
- 「脳・神経に関する語」と「技術・医療機器に関する語」の両方を含む記事だけを残し、BCI／神経刺激／計測・イメージング／神経補綴・リハビリ／デバイス／AI×脳 に分類する。英語の見出しには GAS 内蔵の翻訳で日本語の見出しが付く（無料）。
- 「設定 → 収集元の状態」で、取得できなかった収集元が分かる（サイト側が GAS からのアクセスを断ることがある）。
- 合言葉を入れておくと、しおりが端末間で同期され、「今すぐ収集する」も使える。

## 4. スマホのホーム画面に追加

- iPhone：Safari で `…/ekiden/` や `…/news/` を開き、共有 →「ホーム画面に追加」
- Android：Chrome で開き、メニュー →「アプリをインストール」

一度開けばオフラインでも使える（クラウド保存とニュースの更新はネット接続が必要）。

## 更新するとき

ファイルを差し替えて GitHub にアップロードすると、次にアプリを開いたときに自動で新しい版に切り替わる。
GAS のコードを差し替えたときは、上の「新バージョン」でデプロイし直す。
